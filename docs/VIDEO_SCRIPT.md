# Merilo — 90-секундный демо-ролик (RU)

**Назначение:** страховка на случай, если на защите NFC 2026 не запустится окружение. Регламент видео не требует, поэтому ролик не заменяет живой прототип, а дублирует его.

**Статус на 2026-11-13:** сценарий и субтитры готовы. **Видео не записано** — ждёт живого голоса основателя. `docs/merilo_demo.mp4` в репозиторий не добавлен, потому что озвучки нет, а безголосый дубль не выдаётся за готовый ролик. AI-голос не использовался и не будет использован.

| Параметр | Значение |
|:---|:---|
| Длина | 90 секунд (жёсткий предел 90,5 с) |
| Кадр | 1920×1080, 30 fps, H.264 / AAC |
| Голос | живой, записан основателем; русский |
| Субтитры | [`docs/merilo_demo.srt`](merilo_demo.srt), 12 реплик, UTF-8 без BOM |
| Съёмка | локальный стенд `http://127.0.0.1:8000`, полный экран браузера |
| Монтаж | без вырезанных «чудес»: только реальные клики, ожидание можно ускорять не более чем ×2 и без склеек между нажатием и результатом |

**Почему съёмка локальная, а не с живого адреса.** `https://merilo-nfc.fly.dev` отвечает `HTTP 200` (`version 1.2.0`, проверено 2026-11-13), но в снимке 2026-11-13 на нём **3 кейса** и нет JavaScript-кейса: живой билд отдавал `task-fintech-01`, `task-logistics-02`, `task-edtech-03`. В локальной сборке кейсов **8**, включая `task-web-04` (JavaScript) и режим «свой код» на Go. Поэтому запись идёт с локального сервера, а живой адрес показывается на финальном кадре как демо для жюри; после редеплоя из `main` каталог совпадёт.

## Темп речи и субтитры

Реплики рассчитаны так, чтобы **не превышать 2,5 слова/секунду**: фактический темп — 1,0–2,0 слова/с в тех отрезках, где голос звучит, и около 1,3 слова/с по всему ролику. Разница — паузы на клики и на то, чтобы жюри успело прочитать экран. Субтитры ограничены 42 символами в строке и двумя строками, поэтому одна реплика вмещает 7–12 слов; удлинять фразы нельзя, иначе зритель не успевает читать. Сумма по 12 репликам — **115 слов**.

Если при записи голос «не влезает» в отрезок — **не ускоряйте речь**. Сдвиньте клик на 0,5–1 с раньше или сократите фразу до первой половины; субтитр при этом не меняется, потому что субтитр — это текст сценария.

- [ ] **Чистая база и демо-данные.** Поднять сервер с новой БД: `$env:MERILO_DB_PATH="$env:TEMP\merilo_demo_clean.db"; python scripts\run_demo.py --no-browser`. Файл БД удалить перед стартом, чтобы не осталось старых карточек.

Если прогнать сцену на «боевой» БД, защиту в кадре зафиксировать будет нечем. Пробуйте на `merilo_rehearsal.db`, записывайте на чистой.

- [ ] **Никаких чужих данных.** Скрыть закладки, историю, почту, мессенджеры, второй монитор. Имя кандидата — «Жолынбек Марат», это имя основателя, а не выдуманного клиента.
- [ ] **Браузер.** Chrome, окно 1920×1080, масштаб **100 %** (`Ctrl+0`), тёмная тема, одна вкладка со стендом + одна вкладка с карточкой, панель закладок скрыта (`Ctrl+Shift+B`).

- [ ] **Запись.** OBS или Game Bar, **1920×1080, 30 fps**, курсор виден, микрофон — отдельная дорожка. Проверить 5-секундный тест: звук не клиппует, буквы не «плывут».

## Что должно быть слышно и чего быть не должно

**Слышно:** только живой голос основателя и звуки интерфейса (клики можно приглушить). Музыки нет — она маскирует речь и старит ролик.

**Не должно быть:**

- AI-озвучки, синтеза речи, клонирования голоса. Если голос записать не удалось — ролик не публикуется, а не добивается синтезом.
- Выдуманных клиентов, пилотов, выручки, «наши партнёры». В ролике нет ни одной компании, кроме демонстрационных названий кейсов из `backend/seed_data.py` (`Northwind Systems`, `Atlas Integrations`, `Toolsmith Labs`) — это вымышленные компании внутри кейсов, и на экране они подписаны как часть кейса.
- Обещания конкретного балла: «на этой сборке 91 и 64» — наблюдение, а не гарантия. В кадре показывается фактическое число.
- Слов «семантическая защита», «детектор AI», «мгновенный ИИ», «заменяет интервью».
- Открытого `defense_token`, `MERILO_HMAC_SECRET`, `GEMINI_API_KEY`, демо-пароля, `.env`, e-mail кандидата.

## Приложение A. Go-сниппет для режима «свой код»

Вставляется целиком в поле «Код решения» при выбранном языке **Go**. Проверен на текущей сборке 2026-11-13: `status=verified`, `gate_reached=3`, `evaluation_mode=fallback`, балл **64** (`Needs Work`), `card_hash` `f58ab51f758f` (зависит от `user_id` и имени, на другой базе будет другим).

```go
package main

import (
	"errors"
	"strings"
)

// NormalizeEmail validates an address and returns it lowercased.
func NormalizeEmail(raw string) (string, error) {
	trimmed := strings.TrimSpace(raw)
	if trimmed == "" {
		return "", errors.New("empty email")
	}
	parts := strings.SplitN(trimmed, "@", 2)
	if len(parts) != 2 || parts[0] == "" || parts[1] == "" {
		return "", errors.New("invalid email")
	}
	return strings.ToLower(trimmed), nil
}
```

Почему не «идеальный» код: ролик показывает, что карточка честно ставит `Needs Work`, а не только Gold. Это сильнее, чем второй эталон.

3. «Назовите граничный случай для Go, который может сломать решение: nil-указатели, нулевые значения, пустые срезы и переполнение».

Ответы (каждый ≥ 20 символов, копируются в буфер по одному):

1. `Функция нормализует адрес: убирает пробелы по краям и приводит email к нижнему регистру.`
2. `При пустой строке возвращается ошибка: вызывающий код обязан её обработать и не отправлять письмо.`
3. `Пустой срез после SplitN: проверяю len(parts) != 2 до обращения к parts[1], иначе паника.`

Если вопросы на записи отличаются — отвечайте по смыслу, не читайте заготовку вслух. В кадре важен факт фиксации, а не текст ответа.

## Чек-лист после записи

- [ ] **Длительность ≤ 90,5 с.** `ffprobe -v error -show_entries format=duration -of default=nw=1:nk=1 docs/merilo_demo.mp4` → число не больше `90.5`.
- [ ] **Субтитры синхронизированы.** `docs/merilo_demo.srt` проигрывается поверх записи; каждая реплика начинается не позже чем через 0,3 с после соответствующего действия и не висит после конца фразы.
- [ ] **Субтитры валидны.** 12 реплик, номера по порядку, нет пересечений, последняя заканчивается на `00:01:27,000`, UTF-8 без BOM, ≤ 2 строки и ≤ 42 символа в строке.
- [ ] **Нет AI-голоса.** Прослушать первые 10 секунд и последние 10: живая интонация, дыхание, без артефактов синтеза. Если голос синтезирован — ролик не публикуется.
- [ ] **Нет фальшивых данных.** В кадре нет клиентов, пилотов, выручки, «уже используют». Названия компаний в кейсах — вымышленные, это часть демо.
- [ ] **Нет секретов.** Покадрово проверить 0:24–0:32 и 0:55–1:04: не видно токена защиты, ключей, `.env`, демо-пароля, адресов почты.
- [ ] **Экран читается.** 1080p, текст не мыльный, курсор не закрывает балл; при необходимости — увеличить масштаб браузера до 110 % и перезаписать, а не растягивать видео.
- [ ] **Звук.** Речь громче кликов, нет клиппинга, нет щелчка в начале.
- [ ] **Файл.** `docs/merilo_demo.mp4`, H.264 + AAC, < 50 МБ; если больше — перекодировать `ffmpeg -i in.mp4 -c:v libx264 -crf 23 -preset slow -c:a aac -b:a 128k out.mp4`.
- [ ] **Честная подпись.** В описании ролика: «записано на локальной сборке 2026-11-13, модель не использовалась (fallback), баллы — наблюдение».
