## Описание

```
ЗАДАЧА
Найм разработчиков держится на непроверяемых сигналах: резюме, самооценка, «участвовал в проекте». Заказчик не может отличить реальный навык от красивого описания, а кандидат без имени в индустрии не может доказать навык быстрее, чем за шесть недель отборов.

Merilo превращает решение реальной рабочей задачи в публичную Verified Skill Card — карточку с баллом, разбором и криптографической подписью.

ДЛЯ КОГО
B2B-сегмент: продуктовые команды и агентства, нанимающие 3–15 разработчиков в год; техлиды и HR, тратящие 20+ часов на скрининг; школы и буткемпы, которым нужно подтверждать трудоустройство выпускников объективными данными, а не отзывами.

ЧТО УЖЕ РАБОТАЕТ
Три реальных микро-кейса из практики (финтех, логистика, edtech). Кандидат присылает код, дальше три шлюза:

1. AST-разбор — синтаксис и структура решения без запуска чужого кода.
2. Pattern-based shield против prompt injection — попытка «поставь 100 баллов» блокируется до обращения к модели и не тратит токены.
3. Оценка по рубрике через Gemini Flash со строгой JSON-схемой: чистота кода, архитектура, граничные случаи, плагиат/инъекция, резюме для заказчика.

Результат — карточка: балл 0–100, тир (Gold / Silver / Needs Work / Rejected), перечень проверенного, SHA-256-идентификатор и HMAC-подпись. Карточка публична по короткой ссылке, не редактируется и воспроизводима: один и тот же код у одного и того же кандидата даёт один и тот же хэш на любой свежей базе.

ПРОВЕРЕНО, А НЕ ОБЕЩАНО
— 397 автотестов, покрытие 85,30%, ruff и compileall в CI на Python 3.11 и 3.12 (порог покрытия 80%).
— 8 задач × идеальное / уязвимое / с инъекцией = 24 сценария; на этой сборке проверены три FinTech-пресета (90 / 52 / 0) и в контейнере JS-пресет (91, Gold) и Go own-code (88); все инъекции блокируются на втором шлюзе с вердиктом Rejected.
— Детерминизм хэша подтверждён на двух независимых базах и внутри Docker-контейнера.
— Живой вызов Gemini: исторический прогон 2026-11-09 дал 4,0 с до карточки и цепочку моделей с переходом на lite при 429; в финальной сборке не перепроверялся — UNKNOWN.
— Без API-ключа система полностью работоспособна: детерминированный fallback, p50 83 мс на verify, источник оценки честно подписан в карточке.
— Docker-образ 326 МБ, запуск от непривилегированного пользователя, healthcheck на /api/health.
— Демо без регистрации: жюри открывает и проходит путь до карточки за 60 секунд.

КАК ПРОВЕРИТЬ ЗА 60 СЕКУНД
Открыть демо, выбрать кейс, нажать пресет «Идеальное решение», отправить на проверку — получить Gold-карточку. Скопировать ссылку /card/{hash} в новое окно: карточка публичная и открывается без входа. Повторить с пресетами «Уязвимое решение» (Needs Work) и «Prompt injection» (blocked, шлюз 2, 0 баллов). То же самое локально: docker build и docker run, либо uvicorn на порту 8000 — инструкция в README.

ТЕХНОЛОГИИ
Python 3.11+, FastAPI, Pydantic v2, google-genai (Gemini 3.6 Flash с цепочкой 3.5 Flash и 3.5 Flash-lite), SQLite с WAL для демо и SQL-чертёж PostgreSQL с RLS для продакшна, Vanilla JS и Tailwind CDN без сборщика, Docker, GitHub Actions.

ЧЕСТНЫЕ ОГРАНИЧЕНИЯ
Fallback — детерминированная эвристика, а не второй ИИ; в карточке всегда указан источник оценки. Первичных интервью с заказчиками не проводилось, есть только план валидации. PostgreSQL-схема — чертёж, развёрнутого кластера нет. Мы предпочитаем показать границу применимости, чем обещать sub-second AI.
```
