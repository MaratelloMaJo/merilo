# ADR-001. Один процесс FastAPI раздаёт и API, и статику

- **Статус:** принято
- **Дата:** 2026-11-07
- **Контекст:** национальный финал NFC 2026, демо живьём на чужом ноутбуке и в зале с нестабильным Wi-Fi.

## Контекст

Проект защищается в формате «4 минуты питча + демо + 2 минуты вопросов». Демо должно
запускаться на машине жюри одной командой, без npm, сборщиков, Docker-демона и
второго терминала. При этом UI должен выглядеть как продукт, а не как `curl`.

Альтернатива «React SPA + отдельный API-сервер» требует двух процессов, прокси или
CORS-настройки и шага сборки. Каждый из этих элементов — отдельная точка отказа в зале.

## Решение

Один процесс `uvicorn backend.main:app` на порту `8000`:

- `backend/main.py` объявляет JSON-API (`/api/*`);
- тот же app монтирует `StaticFiles` и отдаёт `static/index.html`, `static/card.html`,
  `static/app.js`;
- страница карточки `/card/{hash}` — серверный маршрут, который возвращает тот же
  `card.html`; данные подтягиваются из `GET /api/cards/{hash}`.

Фронтенд — HTML5 + Tailwind CSS с CDN + Vanilla JS. Сборки нет: файлы читаются
браузером как есть.

## Альтернативы

| Вариант | Почему отклонён |
|:---|:---|
| React/Vite SPA + отдельный API | Два процесса, шаг сборки, риск «белого экрана» на чужой машине |
| Streamlit / Gradio | Не даёт нужного контроля над дизайном и состоянием шлюзов |
| SSR-шаблоны (Jinja2) на каждый экран | Больше кода на те же экраны; JS-состояния шлюзов всё равно нужны |

## Последствия

**Плюсы**

- `python scripts/run_demo.py` — и всё работает; внешних сервисов, кроме CDN и опционального Gemini, нет.
- Нет CORS-конфигурации между фронтом и бэком: origin один.
- Один артефакт для Docker (`Dockerfile` копирует `backend/`, `static/`, `sql/`).
- Тесты API идут через `TestClient` без поднятия второго сервера.

**Минусы и как компенсировано**

- Нет code splitting и SSR → первая загрузка зависит от CDN Tailwind. При падении
  сети остаётся «голая» вёрстка; для этого есть `docs/offline-demo.html` и скриншоты.
- Vanilla JS требует дисциплины: состояние живёт в одном модуле `static/app.js`,
  без фреймворка с реактивностью.
- Статика не версионируется по хэшу → агрессивный кэш браузера может показать
  старый `app.js`; в демо решается жёстким обновлением страницы.

## Доказательства

- `backend/main.py:578-600` — раздача `index.html` и `card.html`.
- `static/` — 4 файла, `node --check static/app.js` → exit 0.
- `Dockerfile` — один процесс, `HEALTHCHECK` на `/api/health`.
- `docs/DEPLOY.md` — запуск без сборки.
